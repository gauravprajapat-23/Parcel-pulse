# Parcel Pulse

An original, offline-first, one-tap parcel-routing game for Godot 4.

**Phase 1:** a deterministic routing board with three destinations, junction switching, scoring, mistakes, restart, pause, and automated GDScript regression tests.

Open `project.godot` in Godot 4.x and run the project. No accounts, internet, external assets, or advertisements are needed.

See the project files and `tests/README.md` for running the headless test suite.
